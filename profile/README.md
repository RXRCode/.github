## `> whoami`

**RXR Code** is an independent software studio building focused products and developer tools around modern commerce.

We work where **Shopify**, **SaaS**, **e-commerce infrastructure**, and **developer experience** meet.

```yaml
organization: RXR Code
website: https://rxrcode.dev

focus:
  - Shopify Engineering
  - SaaS Products
  - Developer Tools
  - Open Source
  - E-commerce Infrastructure

philosophy:
  - useful over complicated
  - focused over bloated
  - maintainable by default
  - built around real workflows
```

## Engineering principles

```diff
+ Solve a real problem first.
+ Keep the product focused.
+ Build for maintainability.
+ Optimize the developer experience.
+ Ship early and learn from use.

- Complexity for complexity's sake.
- Features without a clear job.
- Lock-in where openness works better.
- Abandoned experiments presented as products.
```
